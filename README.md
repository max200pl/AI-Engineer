# AI Engineer

Личный проект для изучения AI Engineering.

## Структура
- `Learning/` — конспекты и учебные материалы
- `notebooks/` — Jupyter-ноутбуки для экспериментов
- `src/` — переиспользуемый код
- `data/` — данные (не коммитятся)

## Окружение
```bash
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписать ключи
jupyter lab
```
